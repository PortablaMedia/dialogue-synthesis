## What is this? / Vad är detta?

**English**

Dialogue Synthesis is a lightweight model for preserving important decisions, rationale and reusable lessons from qualified dialogues with AI agents — so that knowledge and stringency survive across sessions, tools and people. The package consists of four Markdown files: a template, a user guide, an ingestion prompt and a readme.

**Svenska**

Dialogsyntes är en lättviktig modell för att bevara viktiga beslut, motiveringar och återanvändbara lärdomar från kvalificerade AI-dialoger — så att kunskap och stringens överlever mellan sessioner, verktyg och personer. Paketet består av fyra Markdown-filer: en mall, en användarguide, en inläsningsprompt och en readme.
